# SoulCast 响应式混合布局执行方案

## 🎯 执行目标

实现响应式混合布局策略，为不同屏幕尺寸提供最佳用户体验：

- **桌面端 (1280px+)**: 左中右三栏布局
- **平板端 (768px-1279px)**: 左中双栏布局  
- **移动端 (<768px)**: 上中下垂直布局

## 🛠️ 技术实现细节

### 响应式断点配置

```css
/* Tailwind CSS 断点 */
xs: 475px    /* 超小屏手机 */
sm: 640px    /* 小屏手机 */
md: 768px    /* 平板 */
lg: 1024px   /* 小型桌面 */
xl: 1280px   /* 标准桌面 */
2xl: 1536px  /* 大型桌面 */
```

### 布局结构

#### 桌面端 (1280px+)
```
┌─────────────┬─────────────────┬─────────────┐
│   Sidebar   │     Feed      │ RightPanel  │
│  (275px)   │   (600px)    │  (350px)   │
└─────────────┴─────────────────┴─────────────┘
```

#### 平板端 (768px-1279px)
```
┌─────────────┬─────────────────┐
│   Sidebar   │     Feed      │
│  (275px)   │   (700px)    │
└─────────────┴─────────────────┘
```

#### 移动端 (<768px)
```
┌─────────────────────────────────┐
│        MobileHeader             │
├─────────────────────────────────┤
│            Feed                 │
├─────────────────────────────────┤
│        BottomNav                │
└─────────────────────────────────┘
```

### 关键 CSS 类

```css
/* 桌面端 */
.hidden.lg\\:block { /* 显示右侧面板 */ }
.xl\\:w-\\[275px\\] { /* 展开侧边栏 */ }

/* 平板端 */
.hidden.md\\:block { /* 隐藏右侧面板 */ }
.md\\:max-w-\\[700px\\] { /* 扩展主内容 */ }

/* 移动端 */
.md\\:hidden { /* 隐藏桌面组件 */ }
.min-w-full { /* 全宽布局 */ }
```

```tsx
// 1. 更新 MobileHeader 菜单项
const menuItems = [
  // ...existing items
  { id: 'new-page', label: 'New Page', icon: NewIcon },
];

// 2. 更新 View 类型
type View = 'home' | 'explore' | 'new-page' | ...;

// 3. 添加路由处理
case 'new-page':
  return <NewPage />;
```

### 响应式样式
```tsx
// 桌面端显示
<div className="hidden md:block">

// 移动端显示  
<div className="block md:hidden">

// 响应式宽度
<div className="w-full md:w-1/2 lg:w-1/3">
```
